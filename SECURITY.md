# Security policy

## Reporting a vulnerability

Please report a vulnerability privately, not in a public issue or pull request.

Use GitHub's "Report a vulnerability" on this repository: open the **Security**
tab and choose **Report a vulnerability**, or go to
<https://github.com/jimutt/spov/security/advisories/new>. Say what you found,
how to reproduce it, and which version or commit you tested.

Fixes ship in a new release. If you are running a shared server, see
[Running a shared server safely](docs/security.md) for what spov does and does
not protect against.
