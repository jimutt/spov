## Context

macOS users, and Linux users of Homebrew, expect `brew install`. goreleaser can write a cask into a tap repository on each release.

## Decision

- The tap is `jimutt/homebrew-tap`, so `brew install jimutt/tap/spov`.
- goreleaser's `homebrew_casks` writes `Casks/spov.rb` there on each release, from the same archives and checksums. The cask installs the binary and nothing else; it strips the quarantine attribute, since the binary is not notarised.
- It pushes with a token for the tap alone (`HOMEBREW_TAP_TOKEN`, a fine-grained token with contents write on that repository). Without the secret the cask is not uploaded (`skip_upload: auto` for prereleases, and the step is skipped when the token is empty), so a release never fails for want of a tap.
- The tap repository is created by the maintainer; the workflow never creates repositories.

## Rationale

A cask generated from the release cannot drift from it, and a token scoped to the tap cannot touch the main repository.

## Consequences

- Creating `jimutt/homebrew-tap` and its token is a one-time manual step, listed in the release docs.
