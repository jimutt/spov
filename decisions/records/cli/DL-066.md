## Context

For a synced launch, `Env.resolveSyncLaunch` (`internal/cli/sync.go`) matches the local checkout's remote to a configured platform (DL-027). When several platforms match and neither a repos entry nor the account decides, `matchPlatformForCheckout` returns an error that `resolveSyncLaunch` discards unless `--repo` named a platform. The launch then falls back to local-bundle mode, so the sandbox has no origin, and the "several configured platforms match … pass --repo" message is never shown.

## Decision

Proposed: an ambiguous match ends the launch with that message, and only a checkout that matches no platform falls back to local-bundle mode.

## Consequences

A user with two accounts on one host learns to pass `--repo` instead of getting a sandbox that cannot push.
