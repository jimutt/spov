## Context

The session list shows each session's last message (`LastMessages`, DL-115: the newest message of a root conversation). OpenCode stores more than speech as messages: a turn's end is a message of type `idle`, a model switch is one of type `model-switched`, and an assistant message that only called tools has no text. Each has no text, so a finished session's row read "idle: …" and said nothing about the session.

## Decision

`LastMessages` answers each session's newest root-conversation message whose text is not empty or only whitespace. A session with no such message is absent from the answer, as one with no message is, and its row says nothing is recorded yet.

The rule is on the text, not on a list of message types, so a type OpenCode adds later is left out the same way while it carries no text. Postgres filters in the query (`btrim` over space, tab, newline and carriage return) and the memory store with `strings.TrimSpace` in its scan.

## Rationale

A preview exists to say what a session is about. A marker with no words cannot, and the newest message with words is still the most recent thing anyone said.

## Consequences

- The preview of a finished session is the agent's or the person's last words, not the turn's end marker.
- A subagent's report and spov's own continuation carry text and can still be a preview.
