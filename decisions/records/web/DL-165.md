## Context

A stopped session that could resume drew a box of its own (`ResumeComposer`): a sentence over it ("This session has stopped. What you write here is sent once it runs again."), a "Resume and send" button, and on a press a second step holding a paragraph about the snapshot or the transcript and a "Resume and send" / "Not now" pair (DL-090). It looked and behaved unlike the composer of a running session. A message waiting to be read carried a sentence under it ("Waiting: the agent reads it once its current step finishes.", with more on a handover). The page is meant to be clean and quiet, and these explained in words what the context already shows.

## Decision

- A stopped session that can resume, with no job, draws the ordinary composer with the placeholder "Resume session" (`Composer`'s `resume` prop). It has no status line, no model chip and no options. Send resumes the session with what was written as its first message (`POST /sessions/{ref}/resume` with `{text, id}`, through `resumed`), on one press. As for a send, the box clears at once and keeps its focus, a refusal gives the words back, and Enter sends where it sends a message (DL-155, DL-106). An answer it cannot read (`Committed`) keeps Send off, so the box never resumes twice (DL-061's guard).
- `ResumeComposer` and its second press are removed. The sidebar's Resume stays, behind its own question (`resumeQuestion`), for a resume with no message.
- A message waiting to be read says one quiet word under it: "Waiting", or "Queued" for one sent to be read when the turn ends (`queuedNote`), with Cancel beside it as before. When it is read is said once, beside the composer's choice (`deliveryNote`), and never under each message.

## Rationale

The box a reader writes in is the same whatever the session's state; only its placeholder says what Send will do. Writing a message and pressing Send is already a deliberate act, so a second press asking "are you sure" adds text without adding safety, while the `Committed` guard still stops a second sandbox being bought by mistake. The waiting word with Cancel is enough to show the message is not yet read and can be taken back.

## Consequences

- A resume from the box costs one press, where it cost two; the sidebar's Resume still asks first and is the place to read what a resume brings back.
- On a keyboard Enter resumes from the box, as it sends a message.
- What a handover does after a waiting message is no longer repeated under it; the choice's own note says it before the send.
