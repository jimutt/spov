## Context

A folded run is drawn as its summary alone ("41 tool calls, 9 thoughts", DL-058). A session whose model writes little to the reader can show nothing but a growing count for many minutes, and a reader cannot tell what it is doing without opening the run.

## Decision

- While the main conversation's turn is in flight (`turnInFlight`), the run at the end of the transcript adds what it did last to its folded summary: ` · ` and `latestAction` (a tool call's name and input, else `thinking` and the thought), on the same one line, truncated to it.
- Only the newest run and only while folded. Once the turn ends, or anything else is drawn after the run, the summary is the count alone.
- A run inside a subagent's card does not add it: the card's own line already names its child's latest action (DL-112).

## Rationale

The newest step says more than the count does about whether a long silent turn is going anywhere, and it costs no space on the line already drawn.
