## Context

A run of consecutive tool calls and thoughts is folded into one summary line until the reader opens it (DL-058). Opened, every line was low-contrast monospace: a thought was clamped to two lines in the faintest colour and italic, and a tool call was one truncated line whose whole input was reachable only as a hover title, which a phone has none of. Some models write little to the reader and reason at length, so their thoughts are often the best account of what they did, and the drawing made those the hardest thing on the page to read.

## Decision

- Opened, a thought (`session.reasoning.ended`) is drawn whole: every line, its paragraph breaks kept (`pre-wrap`), in the sans body face at the transcript's `text-md` size and the `soft` colour, not italic, set apart from the agent's own words by a rule on its left.
- A tool call stays one truncated line, now a button (`aria-expanded`). A press opens that call alone: its whole input, indented when it is JSON (`toolDetail` in `web/src/lib/timeline.ts`) and as it arrived when not, in a bounded scrolling box, and its whole error if it failed. Another press folds it. Which calls are open is the run's own state, by entry key, so opening a run to read its thoughts never spills every call's input.
- The log carries no result for a call (a success's content is an array the recorder does not project), so an opened call shows its input and error, not its output.
- A run is still folded and opened as DL-058 says, in the main transcript and inside a subagent's card alike, and the other events in it are drawn as before.

## Rationale

Two presses to a call's full input and one to every thought puts the reasoning first and keeps a long run of calls short. `soft` rather than `ink` keeps thoughts behind the agent's own messages, and the rule marks them as the agent's working rather than something said to the reader.

## Consequences

- An opened run with long thoughts is taller than before.
- A call's opened state is lost when its run leaves the transcript's window and comes back.
