## Context

DL-058 drops OpenCode's plumbing events and the speech events that said nothing; DL-158 draws each thought (`session.reasoning.ended`) whole in an opened run. Some providers send a thought with no words: on a live job run on Claude through OpenRouter (2026-11-22), every `session.reasoning.ended` carried empty text. A run with one line is drawn whole without folding, so such a thought on its own was drawn as its bare event name, "reasoning.ended", in the middle of the transcript, and a folded run counted it ("1 tool call, 1 thought") with nothing to show when opened.

## Decision

`condense` drops a `session.reasoning.ended` whose text is empty or only whitespace, beside the speech events that said nothing. It is then neither drawn, nor counted in a run's summary, nor `latestAction`'s thought. A thought with words is unchanged.

## Rationale

An empty thought says only that the model reasoned, which the agent's next words and tool calls already show. Drawing an event's name is the fallback for an event the page has not heard of (DL-058's rule that a new name is still drawn), not for one it knows to be empty.

## Consequences

- A run whose only content was an empty thought is no longer drawn at all.
- "drops a thought with no words and keeps one that has them" in `timeline.test.ts` guards it.
