A calm layout that carries a dense page of information, with a display face that has authority rather than personality.

Design notes
  • Newsreader is the display face — a structured serif with no decorative wobble, still warm at the reading sizes.
  • Aggregate metrics as a hairline stat row, including live-vs-quota as three ticks rather than a boxed panel.
  • Sandbox age on every entry, with a lifetime track and an idle-timeout warning where it matters.
  • Tight rows — age sits beside the state pill and the cost shares one footline with the age caption.
  • Light and dark, built from one token set — the dark ground is a cool near-black, not an inverted paper.
  • A theme toggle in the header. It follows your system setting until you choose, then remembers the choice.
